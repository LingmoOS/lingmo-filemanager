# 桌面小组件改进（2026-11-08）

参考用户提供的 macOS 日历与世界时钟截图，保持 Lingmo 的主题色和 SDK 绘制体系。桌面小组件属于 Shell 浮层：采用完整磨砂卡片，不套用普通应用窗口的左右或上下内容分区。

## 全局样式与交互

- 12 类组件共享 24px 连续圆角、14px 内边距、16px 卡片间距。保留 176×176、368×176 和 368×368 三种尺寸及已有布局配置。
- 玻璃材质通过 SDK popupGlass 与桌面合成器实现；卡片剪裁子内容，保留细边缘和轻阴影。无玻璃时回退为完全不透明的主题卡片。
- 编辑模式采用清晰边框，不再摇晃内容却留下静止玻璃蒙版；添加和改尺寸同步更新几何，不使用可能在删除后仍访问卡片的入场动画。
- 拖到屏幕底部不再删除或淡出卡片。删除只通过右键菜单或编辑模式中的关闭按钮明确执行。
- 时钟、日历、系统/网速、电池、天气等只读卡片可点击打开相关应用或设置，经 AppRuntime 传递参数数组。

## 组件改进

| 组件 | 变化 |
| --- | --- |
| 日历 | 小号简短月份，统一星期行，更清晰的今日圆点；按实际月份所需的行数分配网格；跨午夜更新今日标记 |
| 世界时钟 | 中号显示四个模拟表盘，附城市、数字时间、今天/昨天/明天与相对本地时差；使用 ICU，避免更改全进程 TZ；稀疏时区配置不再漏城市 |
| 时钟 | 居中时间与日期，调整字重和留白 |
| 系统监视 | CPU/内存标签更清晰、拉开数据层级，保留用量条 |
| 电池 | 大字百分比、主题适配的次要文字、状态和电量条 |
| 正在播放 | 小号卡片的封面、曲名和作者重新分配位置，控制按钮增大，次要文字随主题更新 |
| 便笺 | 增加标题与编辑区域层级，文本颜色随主题刷新 |
| 天气 | 城市与温度字重、状态文字层级优化；无城市时保留明确设置入口，不伪造实时数据 |
| 倒计时 | 所有尺寸显示事件名称，数字/单位统一对齐；修复从“配置文件路径/子文件”读取配置的错误 |
| 网络速度 | 按实际单调时钟采样间隔计算速率；调整大小后对应数值不再沿用未更新的文本 |
| 待办 | 中号也支持直接添加，忽略空白任务；修复行宽为零导致已保存任务不可见；勾选后延迟重建，避免删除正在接收输入的行 |
| 启动器 | 修复 Pins 配置路径与 .desktop 后缀处理，图标按格子缩放、标签最多两行；通过 AppRuntime 启动 |

## 配置入口

右键世界时钟、倒计时或启动器，选择“组件设置…”。

- 世界时钟：最多四个 IANA 时区名称，验证时区有效性；单个槽位留空可隐藏城市，全部留空则使用默认城市。
- 倒计时：事件名称和 YYYY-MM-DD 日期，保存前验证日期。
- 启动器：以英文逗号分隔的应用 desktop ID，支持带或不带 .desktop 后缀。

当前这些设置仍按组件种类共享，非每张卡片独立配置；保留既有 Weather/City 设置方式。便笺和待办继续按实例保存各自内容。


## 组件中心（macOS 参考设计）

以用户补充的组件中心、添加、自定义与设置截图作为交互参考。组件中心遵循项目应用材质规范：左侧玻璃分类栏，右侧不透明内容区；桌面卡片本身仍属于 Shell 玻璃浮层。

- 桌面右键“编辑小组件”进入编辑模式；组件右键也可进入同一中心。
- 左栏提供搜索与 12 类组件入口。搜索同时匹配本地化名称及英文组件标识，不区分英文大小写；无结果时显示空态。
- 右侧呈现所选组件的小、中、大三种预览，保持 176×176、368×176、368×368 的比例，尺寸名称位于卡片下方。
- 预览明确标注为示例。不得为浏览预览启动天气网络请求、媒体订阅，也不得显示用户私人便笺与待办。
- 点按预览按所选尺寸自动寻找空位添加，中心保持打开；拖到面板外的桌面区域则在指针附近放置，吸附网格并限制在工作区内。拖回中心取消添加；右键预览不添加。
- 拖拽时提供与真实目标尺寸一致的半透明占位轮廓。
- 右下角“完成”或 Escape 退出编辑，清理拖拽占位和侧栏玻璃区域。分类与预览可使用键盘 Tab 聚焦、Enter 或空格激活。
- 已添加卡片继续通过右键菜单改变尺寸、配置内容或移除，编辑模式也可点移除按钮。
- 组件中心与桌面卡片共享同一个桌面窗口的 SDK 玻璃形状；关闭中心只清理侧栏蒙版，不清理仍存在的卡片蒙版。无合成器支持时侧栏使用主题实色回退。

### 桌面与通知中心（2026-11-08）

- 设置 → 桌面小组件：分别控制“在桌面显示”和“在通知中心显示”，隐藏不删除布局或内容。
- 颜色风格保存为 DesktopWidgets/colorMode：0 自动、1 单色、2 全彩。自动模式根据桌面窗口焦点切换，编辑时恢复彩色；通知中心属于前景 UI，自动模式使用彩色。
- 单色使用中性文字/强调色；启动器图标以单色轮廓显示，媒体封面使用中性音符替代。颜色策略不改变系统主题，也不灰度化整个桌面。
- 组件中心右上角选择“桌面”或“通知中心”。编辑通知中心不会更改已保存的桌面显示开关；选择桌面编辑则显示桌面组件。桌面支持点击与拖放添加；通知中心按尺寸按钮添加，下次打开时读取更新后的独立布局。
- 通知中心通过 liblingmo-desktop-widgets.so.1 加载版本化 v1 接口，复用文件管理器组件源码，不复制组件。模块不可用时原通知功能仍可使用。
- 通知中心组件位于通知列表之后，随列表滚动。小号可并排，中号占一行，大号占两行；拖动后重新排布并保存顺序。右键可改尺寸、配置或移除。
- 关闭通知中心时释放实际组件、定时器和订阅，下次打开重建。模块句柄保持加载，避免异步任务回调执行已卸载代码。由组件模块显式使用 lingmo-filemanager 翻译域，避免覆盖 Shell 翻译域。
- 独立配置：DesktopWidgets/layout.v1.<output> 保留原桌面布局，NotificationWidgets/layout.v1 保存通知中心顺序，NotificationWidgets/visible 保存通知中心开关。
- 文件管理器提供 EditNotificationWidgets D-Bus 方法；通知中心和设置均调用同一编辑器。跨设备组件不在本轮范围内。

## 验证与范围

独立验证项目：[filemanager/tests/widgets](../filemanager/tests/widgets/CMakeLists.txt)，直接编译全部真实组件源码、WidgetLayer、WidgetGallery，并对 DesktopWindow 宿主编译对象文件，不依赖 FUSE 挂载和文件操作守护进程。

- 全部 12 类组件、真实桌面宿主、D-Bus 应用宿主与通知中心宿主编译通过，设置页通过语法检查。
- 动态模块使用正式包相同的隐藏符号设置，检查 v1 加载、两张小卡并排、中卡换行、关闭释放、重新打开恢复、拖动排序持久化及通知中心隐藏开关。
- 检查自动/单色/全彩策略、编辑时恢复颜色、隐藏保留布局以及通知中心目标不接受桌面拖放。
- 每类的小/中/大尺寸，共 36 种组合完成无头渲染。
- 检查四城市显示、有效/无效时区、进程 TZ 不变、中号待办行可见及拖动到底部不删除。
- 明暗主题、100%/150% 总览与日历/世界时钟组合截图已生成并人工检查。
- 组件中心已生成中文明暗主题的世界时钟与日历截图并人工检查；全部 12 类预览均完成无头渲染。截图使用无玻璃能力下的实色回退，不能替代真实桌面玻璃验收。
- 组件中心检查无结果空态、英文大小写过滤、精确尺寸添加、右键不添加、拖回面板取消、定点放置边界、完成与 Escape 退出、关闭后清理玻璃区域。
- 新增中文词条通过 msgfmt --check；截图测试使用已安装的 en_US.UTF-8 配合 LANGUAGE=zh_CN，避免该环境 C.UTF-8 不启用 gettext 翻译的问题。截图字体使用本机已有的微软雅黑，经临时 Fontconfig 配置加载，未安装或分发字体文件。
- 验证使用临时配置；没有访问用户便笺/待办。天气未设置城市，所以不发网络请求；截图中的硬件状态来自验证环境，应用图标也取决于该环境的图标主题。

没有重编译整个文件管理器或在真实桌面运行，因此玻璃与壁纸的观感、媒体/天气在线状态、真实输入法编辑、配置保存和多屏拖动仍需桌面验收。测试 SDK 包与本机 ICU 开发库版本不同，链接有共存警告；正式构建应使用匹配的发行版依赖。验证后关闭 WSL；提交与推送状态以本次交付记录为准。
